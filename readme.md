# First CI Demo

A simple Python program that predicts a student's result from internal marks and attendance.

## Usage

Run the script with:

```bash
python result_logic.py
```

## Rules

- `PASS` when internal marks are at least 40 and attendance is at least 75.
- `FAIL` otherwise.

## Example

The included example uses 70 internal marks and 85 attendance, producing:

```text
Predicted Result: PASS
```
